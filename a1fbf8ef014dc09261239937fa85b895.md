# EventMitra AI

A mobile-friendly event-planning prototype for birthdays, weddings, anniversaries, school celebrations, and community events.

## Current features
- Event type, budget, guest count, date, vibe, location, and special-request inputs
- INR budget allocation with total calculations
- Event timeline and interactive checklist
- Personalised planning suggestions based on inputs
- Saves the latest plan in the browser using localStorage
- Export plan as a text file
- Responsive layout for phone and desktop

## Important limitation
This version is a functional planning prototype, but it does **not** connect to a real generative AI model yet. Its suggestions are generated from transparent rules. Do not describe the current version as having real AI integration until a model is connected through a secure backend and tested.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Deploy with GitHub Pages
1. Create a GitHub repository named `eventmitra-ai`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the live URL shown in Settings → Pages.
6. Test the live site on a phone and in a private/incognito browser.

## Before competition submission
- Review the official challenge rules and required tools.
- Test all inputs, budget calculations, checklist, and export on the deployed URL.
- Add a real AI backend only if time, rules, and a suitable free tier allow it. Never expose API keys in frontend code or commit them to GitHub.
- Record a short demo of the actual working app.
